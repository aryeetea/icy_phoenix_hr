# Icy Phoenix Employee Management System

The Icy Phoenix Employee Management System is a web-based HR platform designed to support employee records, role-based access, scheduling, and secure authentication. The project was developed as part of an academic systems design assignment and focuses on balancing technical functionality with a clear and user-friendly interface.

This repository reflects the system structure, design approach, and key implementation concepts rather than a fully deployed production environment.

---

## Project Overview

Icy Phoenix is designed to support internal company operations by providing different experiences for employees, managers, and executives. The system emphasizes clarity, security, and usability in everyday HR workflows.

Key goals of the project included:
- Designing a role-aware system with distinct dashboards
- Implementing a secure login and identity verification flow
- Creating a clean and consistent UI for internal tools
- Connecting backend logic with thoughtful user experience design

---

## Core Features

- Employee record management
- Role-based dashboards for Employee, Manager, and CEO users
- Secure login flow using employee number verification
- Two-factor authentication using one-time passcodes sent via email
- Team scheduling and calendar views
- Department-based color badges for visual clarity
- Global CSS styling and cohesive branding

## My Role and Contributions

This project was completed as part of a two-person team. My primary contributions focused on system flow, user experience, and frontend integration.

My responsibilities included:
